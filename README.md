# Oasis

应用编程实践课程作业 - RSS Reader : Oasis

## 项目简介

Oasis 是一款跨平台 RSS 阅读器，支持 Windows、Linux、macOS 三大桌面平台。

## 分支说明

本仓库按平台组织代码，各版本的完整源码分别存放于对应分支：

| 分支 | 说明 |
|------|------|
| `main` | 主分支，仅包含仓库说明，不含具体实现代码 |
| `windows` | Windows 版本源码 |
| `linux` | Linux 版本源码 |

如需查看或运行某个平台的版本，请切换到对应分支：

```bash
git checkout windows
```
